# English Studio 🎬

משחק אנגלית לילד/ה בכיתה ד' (ממשק בעברית): פותחים "ערוץ", עונים על שאלות, אוספים סאבים ולייקים, מנצחים בוסים. PWA – אפשר להתקין בטלפון ולשחק גם בלי אינטרנט.

## הרצה מקומית
```
npm run serve      # http://localhost:5500
npm test           # בדיקות ללוגיקת המשחק
npm run icons      # יצירה מחדש של אייקוני ה-PWA
```
ב-localhost ה-Service Worker כבוי כדי שעריכות יופיעו מיד. לבדיקת אופליין/התקנה מקומית: `http://localhost:5500/?sw`.

## פרסום ב-GitHub Pages (חינמי, HTTPS – נדרש להתקנה בטלפון)
1. יוצרים ריפו חדש ב-GitHub (למשל `english-studio`) ומעלים אליו את כל קבצי התיקייה הזו.
2. Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, Folder: `/ (root)` → Save.
3. אחרי דקה הכתובת תהיה `https://<user>.github.io/english-studio/`.
4. בטלפון: פותחים את הכתובת ב-Chrome/Safari → תפריט → **הוסף למסך הבית / התקן אפליקציה**.

כל הנתיבים יחסיים, לכן האפליקציה עובדת מכל תת-תיקייה. אחרי כל עדכון קוד יש להעלות את הגרסה ב-`sw.js` (`CACHE_VERSION`) כדי שהטלפונים יקבלו את השינוי.

## מבנה
- `src/data/` – מילים (46 עם תמונות + ~85 עם אימוג'י), משפטים, סיפורים, דמויות.
- `src/exercises/` – 10 מצבי משחק, כל אחד עם 3 רמות.
- `src/game/` – סאבים/רמות, משימות יומיות, תגים, סיכום סבב (לוגיקה טהורה עם בדיקות).
- `src/screens/` – Onboarding, סטודיו, משחק, תוצאות, פרופיל.
- `_old/` – הגרסה הקודמת של האפליקציה (לעיון בלבד, אפשר למחוק).
